An API key is optional. You only need one if you want the ✨ Generate tab to create new quizzes and flashcards in-app — studying imported or pre-made content works fine without it.

Keys come from platform.claude.com (the API is separate from a Claude.ai subscription and billed per use — generating a quiz typically costs a few cents). Your key is stored only in this browser's local storage and sent only to api.anthropic.com.
